# Blobtracking.tox

TouchDesigner用の汎用ブロブトラッキングコンポーネントです。
映像の中で「動いているかたまり（ブロブ）」を検出し、それぞれに座標・サイズを割り当てて、フレームをまたいで安定して追跡し続けます。

カメラ映像やムービーファイルなど、映像ソースを問わず使えます。

## これは何をするものか

ざっくり言うと、映像の中で動いているものを四角い枠で囲って、その位置とサイズをリアルタイムに取り出せるようにするツールです。

インタラクティブな映像作品、モーションセンシング、簡易的な人物・物体トラッキングなどに使えます。



## 仕組み（処理の流れ）

ブロブトラッキングは、次の3段階の順番で処理されています。

1. **フレーム差分**：前のフレームと今のフレームを比較して、「変化があった（＝動いている）場所」を検出します
2. **メインスクリプトによる塊検知**：フレーム差分で白く映った部分をひとかたまりの「ブロブ」として認識し、IDを割り当てて追跡します
3. **レンダリング**：検出したブロブを枠として映像に描画します

### フレーム差分が思った通りに映らないとき

フレーム差分に映る白い箇所は、スクリプトが実際に処理する部分です。もし想像している絵より白い箇所が大きすぎたり、逆に小さすぎたりする場合は、`frame_processing` の中にある感度調整のセクションで調整してください。ここが「何を動きとみなすか」の感度そのものです。

## 使い方


https://github.com/user-attachments/assets/4f3b0be7-6e89-4b6f-92a9-b4211431a214




1. `Blobtracking.tox` をTouchDesignerのネットワークに配置します
2. 映像ソース（Movie File In、Device Inなど、種類は問いません）を `Blobtracking.tox` の入力に接続します
3. 出力される `tx` / `ty` / `sx` / `sy` チャンネルから、検出されたブロブの位置とサイズを取得できます
   - `tx`, `ty`：ブロブの中心座標（-1〜1の範囲に正規化されています）
   - `sx`, `sy`：ブロブの幅と高さ（同じく正規化された値）
   - ブロブが複数ある場合、1つのサンプルが1つのブロブに対応します

## パラメータ

`Blobtracking.tox` を選択すると、パラメータページに `Brob track` と `Render` の2つのタブがあります。

### Brob track（検出の調整）



ブロブ本体の感度・消失時間・最大サイズ・最小サイズは、こちらのパラメータで変更できます。
<img width="1002" height="603" alt="スクリーンショット 2026-07-30 23 00 38" src="https://github.com/user-attachments/assets/5ff86405-59b1-4a2b-a6f0-87dc0b0db532" />

| パラメータ | 説明 |
|---|---|
| Birth Frames | 何フレーム連続で検出されたら「ブロブが現れた」とみなすか。小さいほど反応が早くなりますが、誤検出（ノイズ）も拾いやすくなります |
| Death Frames | 何フレーム連続で見失ったら「ブロブが消えた」とみなすか（消失までの時間） |
| Match Dist | 前フレームのブロブと今フレームの検出結果を、どのくらいの距離まで「同じブロブ」とみなすか |
| Smooth | 動きのなめらかさ。大きいほど滑らかに、ただし反応は遅くなります |
| Min Area | ブロブとして認識する最小サイズ。これより小さい検出結果はノイズとして無視されます |
| Max Area | ブロブとして認識する最大サイズ。これより大きい検出結果は無視されます |
| Flip Y | 縦方向の座標を反転させたい場合にオンにします |
| Skip Duplicate Frames | 映像側のフレームが実際には進んでいないタイミングで無駄な再計算をスキップし、負荷を抑える機能です。基本的にはオンのままで問題ありません |
| Reset IDs | ブロブの追跡状態をリセットします |



### Render（見た目の調整）

検出結果を確認しやすいように、ブロブを映像として描画するためのパラメータです。色や太さは自由に変えられるので、作品に合わせて調整してください。

<img width="827" height="393" alt="スクリーンショット 2026-07-31 0 39 02" src="https://github.com/user-attachments/assets/c43cdff1-1393-4057-a8c6-560549f44947" />

| パラメータ | 説明 |
|---|---|
| Line | ブロブ同士をつなぐ線を表示するかどうか |
| Line Color | 線の色（RGB） |
| Line Width | 線の太さ |
| Box | ブロブを囲む四角形（箱）を表示するかどうか |
| Line or Solid | 四角形を「枠線だけ」で描くか「塗りつぶし」で描くか |
| Box Color | 四角形の色（RGB）。出てくる箱の色はここで自由に変更できます |
| Boxline Width | 四角形の枠線の太さ |
| Opacity | 線・四角形それぞれの不透明度 |
